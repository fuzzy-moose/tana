# 04: The preview calculates the model from the favorites in scope

What to build: the collector's preview learns only from the Panda favorites inside the default filter. A value's weight is its smoothed lift against the Panda catalog under the same default filter, and it is never negative. Verdicts and displays are no evidence. The preview reports the number of favorites in scope and, for each weight, how many favorites and catalog galleries carry the value, and the stored candidate keeps those counts. The update deletes every stored model, so the score filter is off until a new model is applied. The recent catalog sample stays real and classes by overrides and score only. Three parts of the preview follow in later tickets: the held-out measurement and the suggested threshold in ticket 06; the new favorites, the active model comparison, the pins and the favorite authors are pinned again in ticket 07.

This ticket changes the collector only. The score page reads fields that this ticket removes, so it throws on the feature branch until ticket 05, which runs next (spec **Fit** 3). The checks stay green, because the web tests mock `fetch`.

## Resolution

Migration `0012_panda_score_models_from_favorites.sql` deletes every model and replaces the verdict count columns with `favorites`/`catalog` per weight and `favorites_in_scope`/`catalog_in_scope` per model. `PreviewScoreModel` (`score_model.go`) reads the favorites in scope (default filter, expunged included) into Go, counts the catalog in SQL only for values with at least `MinSupport` favorites, weighs them with the pure `scoreWeight` (`score_weights.go`), and stores the candidate with its counts; `NoModel` is `no_favorites` without a favorite in scope. The recent sample classes by overrides and score only. `collectorapi` has the ticket-04 shapes (`ScoreEvidence`, `ScoreWeight`, one-class `ScoreHeldOut`, `ScoreRecent`, `ScoreNoFavorites`). The fold measurement and the verdict-based tests are gone; new tests are in `score_model_test.go`, `score_weights_test.go`, `storage_test.go` and `TestLocalScoreModel`.
