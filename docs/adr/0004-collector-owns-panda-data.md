# Collector owns Panda metadata and archives

The collector owns Panda metadata retrieval, durable download jobs, and retained original archives, keeping upstream access and collected data independent of Tana library availability. The latest successful metadata is retained indefinitely, including when a gallery becomes unavailable upstream; archives remain until explicit deletion. Retrieving an archive does not consume it or establish local library presence, so delivery can be retried without downloading from Panda again.

Tana obtains metadata and submits explicit retrieval requests through the collector, centralizing upstream access and persistence. Missing metadata during automatic enrichment does not itself submit a retrieval request; enrichment waits for collection already owned by the collector under [ADR 0007](0007-automatic-panda-enrichment.md). Collection follows related gallery references, and retained metadata records its last successful retrieval time so consumers can judge its age without assuming automatic refresh.
