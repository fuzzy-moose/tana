# Explicit cleanup of superseded sources

Cleanup may permanently delete local archives when collected Panda parent references prove that a newer source is present in a registered library; favorites and collector downloads do not establish local possession. Filename-derived Panda IDs are accepted for this explicit, reviewable cleanup, with ambiguous matches skipped, because maintaining a separate verified association is outside the chosen scope. The chain from replacement to superseded source must be complete; the superseded gallery's own metadata and history before it need not be known, and intermediate versions need not have local sources.

Cleanup spans libraries and shows old sources with their surviving replacements before confirmation. Replacement presence is rechecked before deletion without content validation. Directory sources may serve as replacements but are excluded from deletion, as are sources used by independent galleries; source-linked galleries follow their source's deletion lifecycle.

Eligible archives start selected, with exclusions available before one confirmation showing paths, replacements, and total size, so bulk cleanup does not require reviewing libraries or selecting candidates individually. Cleanup uses already collected metadata and leaves unresolved sources untouched.
